- **The first solve after launch is excluded from the p95.** It took 309 ms for the 1-D case and 115 ms for the system, because it includes warm-up.

- **Engine ready went from 956 to 1022 ms since this morning.** That is still well under the bar.
- **Some of these numbers are only in logcat.** The cold-launch numbers are in `.coord/device-runs.jsonl`. The solve and plot numbers come from annabell's logcat report, because `device_run.py page` doesn't write to that file yet.
