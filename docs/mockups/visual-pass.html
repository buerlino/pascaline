Visual pass: final mockups

R12a's seven screens, redrawn with everything decided since, plus the new Appearance page. Static drawings at 360 px wide (a phone is about 412), dark and light; open this page on the phone. Colours are the Pascaline values now in app/src/style.css (R50b, merged), so what you see here is what the app draws. Nothing else here is built yet.

What changed since R12a, and where each comes from
  • Colours: Pascaline dark and light (decisions.md "R50"; built in R50b). ≈ in the approximate colour, ⚠ in the warning colour, the picked row and the caret in the focus colour, the plot curves from the per-brightness list.
  • Top cluster R3 (decisions.md "R15c"; R15c2–R15c3): U1–U6 on the left (all empty until you set them from Find, R4b), the round pad with no OK, then View | Esc, Undo | Copy, ⇤ | ⇥. Their Shift layers are the small legends; Help is dimmed until it is built.
  • Status line (R15c1): the place name with ▾ opens Apps; in an app the Symb, Plot and Num tabs sit beside it; ☰ at the right opens the view's menu, or the picked row's menu. The chips still open Mode.
  • Entry line 52 px (your note #54; R12b).
  • Digit groups (R55): results group digits in threes from the decimal point, on a side with five or more digits.
  • Settings is a list of rows (R49), each opening its own page. Appearance is the first row (R50e), and Decimal mark is a row (R57). Settings is also the last row of every ☰ menu (key 0 in Home).
  • Plot: Menu left the tools bar, because ☰ on the status line holds it.
