# Shift brief

**No shift is planned.** The standing rules (sections 1, 3–6 and 9–11) are in [rules.md](rules.md); read them first.

When a shift starts, this file gets that shift's own parts:
- **0. State at start** and **0a. Tasks, in order**, with the goal in one line and which workers to spawn;
- **2. Read before you start**, including what is already decided and not to be reopened;
- **7. Assignments**, one subsection per worker (model and effort, tasks in order, branch name);
- **8. Definition of done**, with the bars and the gates Henri verifies himself.
