## What you can do now

Each answer appears in the history, drawn in 2D: decimals in **Home**, exact results in **CAS**. Cancel stops a long job without losing your history or variables. The history survives a restart, and the system keyboard never appears. `./build.sh` builds the APK from a clean clone.

Cancel on a long CAS job: ready again after 359–375 ms (p50), with the variable and the history intact every time. Slowest single inputs are `solve-trig` (~180 ms) and `heavy-int` (~150 ms).

On the way there, the first final run showed that a **saved history slowed everything down**: with ~110 entries, engine ready took 2.1–2.7 s and Enter p95 was ~227 ms. ron fixed it. The history now loads after the keypad, only the newest 20 entries are drawn, and Enter draws only the new entry. A full history now costs about +285 ms at start-up and +20 ms on p95. ron's lazy loading of MathLive also cut keyboard usable from 900 ms to about 660 ms.

**P2: emsdk against the container build** (spike app, 7 cold starts, 5 benchmark runs): engine ready 896 vs 917 ms (+2.3%), first result 1001 vs 1016 ms (+1.5%), benchmark first-call p95 76.7 vs 72.6 ms. The +10% bar is met. The two builds give identical output: 0 differences in 476 golden outputs.

**The engine build is now bit-reproducible.** clang made different code from run to run while Linux randomised memory addresses (ASLR). The release script now builds with ASLR off inside the container, and every build gives `giac.wasm` SHA-256 `ab5ca4eb…3003a`, including a fresh clone.

## Defaults decided (details in docs/decisions.md)
- Home and CAS share variables (one engine) but keep separate histories and separate `Ans`.
- CAS: after 10 s the Cancel button becomes prominent, and nothing is cut off automatically. Cancel restores definitions but not `Ans`.
- Number formats: digits means significant digits; STD/SCI/ENG layout is `assumed` (G2 items 8 and 15).
- Cancel, Clear, history tap, one-shot shift/alpha, one-line mode behaviour (`assumed`).
- Sto▶ is shift + comma, typing `:=` (position `assumed`, G2 item 2).
- a/b makes a plain stacked fraction for now. The mixed-number form (2½) is not built yet (G2 item 17).
- Default angle mode is radians (`assumed`).
- The Tab One benchmark sends the 55 Giac-text inputs through the app's engine, tidy-up and drawing path, skipping only our parser.
- `npm run golden` is the one gate for every engine build, and the G2 checklist is generated from `tests/golden/g2.yaml`.
