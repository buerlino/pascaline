### annabell, A42: the release engine through the gates, branch `p1/annabell-releasegate`
**Lane:** night (queue 125c, after A19; host-cpu only, no device). **Starts when:** now. The freeze needs one green run of it (decisions.md P23 (2); owner, 2026-10-26).
**Why:** `./build.sh` ships `engine/giac/_out/release` (Emscripten 3.1.69 in the pinned trixie container, P2; `build.sh` 48–50), but the golden gate, the canaries, the core list and every device build use `_out/gsl` (emsdk 6.0.12; `scripts/pipeline.sh` 56–57, `tools/device-build.sh` 7). The last golden run on the release engine was A4a (about 2026-10-11), before the G77 pin, patches 0003–0008, the step budget (G82), the bridge exports (G85) and the 1 GB cap. So a green night certifies the dev engine, not the one the APK carries. A8 later runs the same check before signing.
**Read:** `engine/giac/build-wasm-release.sh` (its outputs, the host-cpu lock it takes itself, `SHA256SUMS`); `build.sh` 40–55; `app/scripts/gate.ts` (the stage lines it prints); `app/package.json` (`golden`, `test:core`); `tests/engine/canaries.mjs` (and `PASCALINE_DL_DIR` in a worktree); `tools/devlock.sh`; `tools/README.md` (timings); `scripts/pipeline.test.sh` and `tools/devlock.test.sh` (the shell-test pattern).
1. **Tests first:** `tools/release-gate.test.sh`: `tools/release-gate.sh --dry-run` prints the stages in order with the engine directory each uses (all `_out/release`), and refuses a `GIAC_OUT` that is not the release build; it fails on phase-1 (no script).
2. **`tools/release-gate.sh`** (no change to `pipeline.sh` or `night.sh`): build the release engine unless `_out/release` matches the current patches and pin (reuse the build's own check, or rebuild); then, with `GIAC_OUT=<abs>/engine/giac/_out/release`: the golden gate, the canaries, `npm run test:core` (a free `PW_PORT`). One line per stage, and a last line `RELEASE GATE PASSED` or `RELEASE GATE FAILED: <stages>`. It holds `host-cpu` around the heavy stages.
3. **Run it once** on phase-1 and compare each stage with the same stage on `_out/gsl` (the night's last run). Every difference (a golden case, a canary, a core case) is a backlog line in the report: its input, both answers, and the oracle's value where there is one.
**Done when:**
- The test fails on phase-1 and passes.
- The report holds the run's output and the line `RELEASE GATE PASSED` on phase-1, or each difference with its backlog text.
