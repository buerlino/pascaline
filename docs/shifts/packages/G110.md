### gorge, G110: a census of the kinds of answer Giac gives for Find's main commands, before Find opens them, branch `p1/gorge-findcensus`
**Lane:** night-safe (Opus worker, Opus audit). **Starts when:** G105 is merged (owner, 2026-10-24: R4a waits for G104 → G105 → G110; core-stability report step 9). A measurement and its gate, no feature: Find puts hundreds of commands one tap away, and each may return a kind of answer our layer has never seen (bug-patterns family 5, hunt lead 6; N1 `cas_setup` and `approx_mode` is that kind).
**Read:** `app/src/find/_gen/find-index.json` (tier-1 entries, built by `npm run index`); `tools/find-index/generate.mjs`; `app/src/goldenRun.ts` (how a `latex:` case goes through our parser); `app/src/engine/numeric.ts` (`shapeOfValue`, the bridge-3 kinds); `tools/probes/sweep/` (the pattern: a seeded run, a judge, a known list, a gate stage); `docs/research/bug-patterns.md` sections 3 (family 5) and 6 (lead 6).
1. **The census:** for every tier-1 entry, its sample input typed as keyboard LaTeX, in Home and in CAS, with two or three argument kinds where the entry takes numbers (an integer, a decimal, a negative, a list); record the bridge-3 kind of Giac's answer, what we show and the mark. Classes: shown with a right mark (the oracle checks numbers, as the sweep's judge does); refused with a message; Giac's raw text; a wrong value or a wrong mark; a state change (a setting or a name left behind).
2. **The probe and the stage:** `tools/probes/find-census.ts` with a README row; a gate stage `findcensus` (desktop under 5 minutes) with a known list, so a class change fails it, as `sweep` does.
3. **The findings:** each raw text, wrong value, wrong mark or state change is a backlog bug line (rules section 9) with its rerun command; the report gives the counts per class.
**Done when:**
- The stage passes with its known list; the probe's README row is in; the report gives the class counts and the runtime.
