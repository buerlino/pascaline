### annabell, A49: the web version survives updates and bad deploys, branch `p1/annabell-pwaharden`
**Lane:** night-safe (no device). Sonnet, **audit Opus**. **Starts when:** R91 is merged (both change `app/src/main.ts` and the lazy chunks; step 2's chunk reload is about R91's chunks); before A45.
**Why:** (phase-1 `fa52380`) `app/public/manifest.webmanifest` has no `id`, so an installed app's identity follows `start_url`. `app/pwa/sw.js` keeps one versioned cache and never skips waiting, so an update waits until every tab is closed and nothing tells the user. The engine files keep fixed names, so during a deploy a new `giac.mjs` can meet a stale `giac.wasm` from a CDN cache, and the new worker caches the pair. Nothing asks for persistent storage, so a browser may evict the user's history. A lazy chunk missing after a deploy fails with no recovery. There is no way to switch a broken worker off. Frozen for good (decisions.md "The release path"): the worker's path and scope, the IndexedDB name, the manifest `id` once set here.

**Read:** `app/pwa/sw.js`; `app/vite-plugin-pwa-lite.ts`; `app/src/pwa.ts`; `app/public/manifest.webmanifest`; `app/playwright.pwa.config.ts` and its tests; `app/vite.config.ts`; the i18n table; docs/04 section 8 (the start budget).
