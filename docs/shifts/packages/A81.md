**Why:** (owner, 2026-11-06) v0.1.0 goes out on Sat 11-07 and the first users will report bugs. A free-text issue rarely says the mode, the settings or the exact input, and a calculator bug cannot be reproduced without them. `n62-dev/n62` has Issues on and no `.github/ISSUE_TEMPLATE/`.
**Read:** CONTRIBUTING.md (its issue paragraph, `:3`); README.md (where it points to help); `app/src/views/` About (what it shows as the version; do not change the app); GitHub's issue-form schema (`body` of `input`, `textarea`, `dropdown`, `checkboxes`, `markdown`).
1. **Test first (failing on phase-1):** a vitest test (`app/scripts/issueForms.test.ts`, with the `yaml` package already in app/package.json) reads `.github/ISSUE_TEMPLATE/*.yml`: each parses; `bug.yml` has `name`, `description`, `labels: [bug]` and the required fields below with unique `id`s; `feature.yml` has `labels: [enhancement]`; `config.yml` sets `blank_issues_enabled: false` and a contact link to `https://n62.dev/`.
2. **`bug.yml`**, title prefix `Bug: `, short plain words, each field with a one-line hint:
   - *Version* (input, required): "About shows it, e.g. 0.1.0".
   - *Where* (dropdown, required): Android app, Web app (n62.dev), Other.
   - *View* (dropdown, required): Home, CAS, Plot, Units, Find, Settings, Other.
   - *Settings that matter* (input): angle mode (DEG/RAD), decimal mark, exact or approximate.
   - *What you typed* (textarea, required): "exactly as entered; Copy as text pastes it".
   - *What N62 showed* (textarea, required), with the mark (=, ≈, ⚠) if there was one.
   - *What you expected* (textarea, required), and where the right value comes from if known.
   - *Screenshot* (textarea, optional) and *Device* (input, optional: phone model and Android version, or browser).
   - A short `markdown` line at the top: no personal data; one bug per issue.
3. **`feature.yml`**, title prefix `Idea: `: *What you want to do* (required), *How you do it today* (optional), *Anything else* (optional).
4. **`config.yml`**: `blank_issues_enabled: false`; one contact link, "Website", `https://n62.dev/`.
5. **Links:** CONTRIBUTING.md's issue paragraph and README.md's help or feedback line point to `https://github.com/n62-dev/n62/issues/new/choose`. The app does not change (the start chunk stays pinned).
**Done when:** the test passes and `npm run gate` is green; the three files exist and parse; the report shows the rendered field list of `bug.yml` for the owner, who reads it on GitHub after the push (the owner's look; a form only renders on the default branch).
