### gorge, G80: each inexact constant carries its basis, branch `p1/gorge-m4-constbasis`
**Lane:** night-safe (Sonnet worker, Opus audit). **Starts when:** the owner's OK; before G81. From libqalculate #1045 (closed 2026-10-20): the maintainer kept formulas, not stored CODATA values, because stored values break correlations (Z₀·e²/(2h) is exactly α). Our index stores every constant flat (value and a rounded σ), so the correlation is lost in our layer.
**Read:** `tools/find-index/generate.mjs` (the constants loop near line 590, `siOf` near 309, `roundWithUnc` near 163); `app/src/find/types.ts` (`FindItem`); docs/04 3.3 (the schema); `tools/probes/codata-check.py` (the same formulas, independent inputs); A21's package (`find/factors.yaml` takes the numbers later, so whichever merges second carries `basis` over).
1. **Tests first:** an index test that `mu_0`, `epsilon_0`, `Z_0`, `m_e`, `m_p` and `alpha` each have a `basis`, and that evaluating each basis at its leaves' values gives the item's `value` within its `unc` (fails on phase-1: no field).
2. **The leaves:** the constants whose qalc `<value>` is a number with an `uncertainty` attribute (26 in master's variables.xml: `fine_structure`, `rydberg`, `electron_u`, `proton_u`, `neutron_u`, `muon_u`, `tau_u`, `newtonian_constant`, …). Each leaf gets an index entry `basisLeaves[<id>] = {value, unc}` with qalc's digits unrounded, because `unc` on an item is rounded to 2 digits for display.
3. **The basis:** for each inexact constant, `basis` is its value as Giac text over the leaves as `pasl_<leaf>` names and exact numbers (h, c, e, k, N_A, π), taken from qalc's `<value>` formula by expanding the named constants it uses until only leaves and exact constants are left. A formula the expansion cannot write in Giac (a function qalc has and Giac does not) leaves `basis` out, and the report lists it.
4. **No other change:** `value`, `unc` and what Find shows stay byte for byte; the index grows by the new fields only (size in the report).
**Done when:**
- the test of step 1 passes for every constant with a `basis` (not only the six); the constants without one are listed in the report with the reason;
- `npm run index` then `FIND_INDEX=required npm test` pass; the index size before and after is in the report.
