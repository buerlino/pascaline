2. **The change:** `restore()` replays values, assumptions and inputs kept as typed as today (G29's batches). It keeps functions (`kind: "fn"`, one balanced command) in a pending map instead, and still records every entry in the log, so Vars, Find, the mark facts and export do not change. `need(text)` also loads every pending function whose name is a word in `text`, and then, before loading, every pending function named in that function's body, transitively. A closure goes to Giac in one batch, with G29's fall-back to one command at a time. A text that names `VARS`, `expr`, `rm_all_vars` or `restart` loads them all first. A new definition or a purge of a pending name drops it from the map. The replayed commands (values, `other`) also go through `need()`, so a value that names a function finds it.
3. **The numbers:** `restore()`'s time for the 200 programs in Node, before and after (in the report); the first call of one library function, before and after.
4. **Docs:** docs/04 6.2 says functions load on first use and gives the rule above; 8.3's `defs` row names G83.
