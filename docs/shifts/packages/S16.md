### sofia, S16: the hardening pass, an Opus pass over the instruments
**Lane:** night (an Opus pass, not a worker: `scripts/pipeline.sh pass <n> "G61 G62 G63 G64 A19" "S16: run the instruments at volume and triage, docs/shifts/packages/S16.md"`). **Starts when:** G61, G62, G63, G64 and A19 are merged. From r16's package S16 ([r16](../../archive/r16-verification.md) sections 4, 5).
**Read:** brief section 0c "Opus pass"; the reports of G61–G64 and A19; r16 section 4 ("When, in order") and 6 ("What this cannot prove"); `docs/backlog.md` "Open bugs".
1. **Tests first:** no code (a pass). Before the volume runs, each stage's gate-size run is green on phase-1, so a failure at volume belongs to the volume.
2. **At volume:** each sweep stage in its nightly mode with three rotating seeds (G61: about 20,000 inputs; G62, G63, G64 at ten times their gate size), each under `timeout`; A19's stage on the emsdk build.
3. **Triage** every new failure into one of: ours (a FIX line, or a fix package when it is more than a fix); Giac's (a line in backlog "Upstream reports", and a patch package when the cause is local, P19); a convention (a G2 question in `tests/golden/g2.yaml`); unstable in the oracle (dropped, with the seed).
4. **Write** each reachable wrong answer as a backlog "Open bugs" line before the pass ends (rules section 9), with label, base commit, rerun command and reach; ids for packages only as rules section 9 says.
**Done when:**
- The pass's reply lists every failure with its triage; the doc commit holds the new backlog lines and G2 questions; the known-failures lists name only open backlog ids.
