Each `Alternative` = `{ slot: UnitSlot, text, kind: "si" | "siPrefixed" | "target" | "pad" | "typed" }`, in r17 0.2's order: coherent SI with no prefix (picked as r17 section 3 says: typed, then the pad's tap unit, then the base form from the dimension key; never Bq for Hz, never Gy for J/kg), SI with its prefix, target, the pad cell's units of that dimension in pad order (tap, ↑, ↓, then a second cell, then user cells; a power of a pad quantity with no cell of its own, as L², the same power of that cell's units), typed units; repeats and the shown unit dropped; none for a pure number or a `null` dimension. Temperatures: an absolute result (`job.absTemp` or a °C/°F end slot) gives K, °C, °F; an interval gives K, Δ°C, Δ°F. Angles: °, rad (no rev: G32).
4. **A tap is an end slot:** `withEnd(req, alt): UnitRequest` sets `end` to the alternative's slot; the caller runs `Calc.units()` again, so value, mark, σ and note come from the evaluator. No conversion in TypeScript.
5. **`units.targets`:** `{dimKey: unitId-or-slot}` in the stamped store beside the user keys (`storage.ts`), read and written by two functions here; a tap writes it. It orders the row only and never changes the unit shown (G25 stays the only rule, r17 section 3).
