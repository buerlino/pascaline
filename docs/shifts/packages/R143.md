- The layers that open a sheet (`spec/keyboard.yaml`, `special:`): `vars` (Vars, Find on the user's names), `find` (Math), `memory` (Shift + Math), `tmpl` (Tmpl), `relations` (Shift + 6), `symbols` (Shift + 9), `mode` (Shift + Fmt), and after R146 `settings` (Shift + Help). `units` (Shift + Tmpl) opens the unit view, a mode, not a sheet: no mark. A user key that holds `apps`, `menu`, `tmpl`, `find`, `vars`, `memory`, `mode` or `settings` gets the mark on that layer too.
