## Workarounds in our code
Giac behaviour we handle in our code instead of a patch (P19: a patch when the cause is local in Giac's source and has an MPFR path), one row per behaviour. **Canaries:** `GIAC_OUT=<abs dir> node tests/engine/canaries.mjs` (S17; in a worktree also `PASCALINE_DL_DIR=<main checkout>/engine/giac/_downloads`, for `patch-canary.ts`'s tarball) asserts each row on the raw engine (plain `giac_eval`) and runs `patch-canary.ts` for the patches; it ends `PASS canaries: 19 workaround rows` while Giac still does every one, else prints the rows that FLIPPED (their workaround may go at that pin, G77) and exits 1. **Probe:** a row's inputs, `MODE=raw node tools/probes/engine.ts 'Digits:=<d>' '<input>'` (the canary prints that line when it flips). **Upstream:** backlog "Upstream reports"; the Giac drafts are named by their title (owner's `../outreach/upstream-reports.md`).

## Not patches, but build choices that change Giac's source tree or behaviour
All of these live in `build-wasm.sh`; compile defines and configure flags are listed in `../README.md` ("Build choices").
- The prebuilt `doc/giacwasm.{js,wasm}` from the tarball are deleted right after unpacking (never used or shipped).
- `config.h` (from Giac's `configure`) gets `HAVE_LIBPTHREAD`, `HAVE_PTHREAD_H` and `HAVE_LIBRT` commented out: no threads in the browser build (they would need SharedArrayBuffer + COOP/COEP). Only the root `config.h` gets the edit: `configure` (`configure.ac:688`) has already copied it to `src/config.h`, which every `#include "config.h"` in `src/` finds first, so the compiled files still see them defined (found by G77, on both pins; decisions.md "Needs the user"). Without `-pthread` Emscripten links its stub `pthread_create`, which returns an error (`system/lib/pthread/library_pthread_stub.c`), and the golden gate passes as built.
- Files from `libgiac_la_SOURCES` in `src/Makefile.am` that are not compiled:
  - `markup.cc` (improved LaTeX export by L. Marohnić): with `EMCC2`, `tex.cc` defines stand-ins for its two entry points. Revisit if KaTeX output needs the better exporter.
  - QuickJS and its Giac bridge (`--disable-quickjs`): `quickjs.c`, `quickjs-libc.c`, `libbf.c`, `libregexp.c`, `libunicode.c`, `cutils.c`, `js.c`, `qjsgiac.c`, `caseval.c`, `graphic.c`.
  - KhiCAS calculator UI: `kadd.cc`, `kdisplay.cc`, and `qrcodegen.c` (QR-code generator; nothing we compile needs it, the link succeeds without it).
- `wasm/stubs.cc` provides `sigsuspend` (desktop-GUI child processes only) and `giac_gen_renderer` (WebGL 3D, not built).
- `wasm/api.cc` provides an identity `gettext()`; engine messages stay English.
